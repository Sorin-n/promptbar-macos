# PromptBar

PromptBar is a native macOS prompt library and quick-access menu bar app.

It provides prompt organization, fast menu bar access, a larger workspace, library import, drag-and-drop transfer, and customizable shortcuts and themes.

## Requirements

- macOS 13 or later
- Swift 5.9 or later

## Run

```bash
swift run PromptBar
```

## Test

```bash
swift test
```

## Web prototype

The PromptBar web prototype is included in `PromptBarWeb/index.html`. Open this file directly in a browser; no build step is required.
